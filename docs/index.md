# The Official LEDGER Documentation

Welcome to the official documentation for the Linked Environmental Data and Greenhouse Emissions Resource (LEDGER). LEDGER is a data utility to make analysis of emission data easier. At its core is a database that stores emission data for nation states, administrative 1 levels, and cities. The data is harmonized from various sources. Analysis of the data is provided via a REST API and a high-level Python client that abstracts away the API. The ultimate goal is to focus on the science instead of munging data. 

We hope this documentation helps you get started quickly and makes exploring the LEDGER database easier and more productive.
