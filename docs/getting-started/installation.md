# Getting Started

LEDGER currently provides two main ways to access data: a REST API and Python client. 
We suggest starting with `ledgerdata`, a Python package that provides a high-level access to the REST API.

This getting started page will walk you through the steps to start using `ledgerdata`. 

--- 

## Installation

`ledgerdata` can be installed via uv or pip. We recommend [uv](https://docs.astral.sh/uv/).

### UV <small>recommended</small> { #with-uv data-toc-label="with uv" }

```sh
uv add ledgerdata
```

### pip

```sh
pip install ledgerdata
```

Now you can start using `ledgerdata` in your projects!
